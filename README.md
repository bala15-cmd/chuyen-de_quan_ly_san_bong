# Quản lý sân bóng - Hướng dẫn chạy bằng XAMPP
1. Chép thư mục `quan-ly-san-bong` vào `C:\xampp\htdocs\` (giữ đúng tên thư mục, vì đường dẫn trong code là `/quan-ly-san-bong/`).
2. Mở XAMPP, bật Apache và MySQL.
3. Vào http://localhost/phpmyadmin, chọn Import, nhập file `database.sql`.
4. Nếu MySQL có mật khẩu, sửa trong `config/database.php`.
5. Mở http://localhost/quan-ly-san-bong/
Tài khoản mẫu (mật khẩu `password`): admin (Admin), nguyenvana, tranvanb (User).
Ảnh sân tải lên được lưu ở `assets/images/uploads/` (cần quyền ghi).
